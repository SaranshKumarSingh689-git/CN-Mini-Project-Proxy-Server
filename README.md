## 2. Why I Chose This Project

I chose this project because it will help me understand practical networking concepts such as **TCP socket programming, HTTP communication, concurrent connections, caching, access control, and network traffic logging**.

I also want to understand how a proxy acts as an intermediary between clients and destination servers.

## 3. Planned Features

The final project is planned to include:

- Multiple simultaneous client connections
- HTTP request parsing and forwarding
- Response caching with cache hit/miss handling
- Domain/URL-based access control
- Network traffic logging
- Handling of malformed requests and unreachable destinations
- Basic performance measurement comparing direct and proxy connections
